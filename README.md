# 경제 퀴즈 게임

## 프로젝트 개요

향후 팀 프로젝트에 참여할 역량을 기르기 위해 파이썬 언어부터 깃과 깃허브에 적응하고 익숙해질 수 있도록 간단한 퀴즈 프로그램을 만들어 보는 것.

## 퀴즈 주제 선정 이유

사람들이 많은 관심을 가지고 있는 '돈'을 잘 관리하기 위해 알아두면 좋을 경제 지식을 쌓기 위해 선정.

## 실행 방법

- 필요 환경: Python 3.10 이상 (외부 라이브러리 없음)

```bash
git clone https://github.com/kimgilhan83/quiz-game.git
cd quiz-game
python3 main.py
```

> 윈도우에서는 `python main.py`로 실행하세요.

## 기능 목록

| 메뉴 | 기능 |
|---|---|
| 1. 퀴즈 풀기 | 저장된 퀴즈를 한 문제씩 출제하고 채점, 결과와 점수 표시 |
| 2. 퀴즈 추가 | 문제·선택지 4개·정답 번호를 입력해 새 퀴즈 등록 |
| 3. 퀴즈 목록 | 등록된 퀴즈를 번호와 함께 표시 |
| 4. 점수 확인 | 지금까지의 최고 점수 표시 |
| 5. 종료 | 프로그램 종료 |

공통 처리:
- 숫자 입력: 앞뒤 공백 제거, 문자·빈 입력·범위 밖 숫자는 안내 후 재입력
- `Ctrl+C`, `Ctrl+D`: 안내 메시지 출력, 저장 후 안전 종료
- 저장 파일이 없거나 손상된 경우: 기본 퀴즈로 시작

## 파일 구조

```
quiz-game/
├── main.py        # 프로그램 전체 (Quiz, QuizGame 클래스 포함)
├── README.md      # 프로젝트 설명서
├── .gitignore     # Git이 추적하지 않을 파일 목록
└── state.json     # (실행 시 자동 생성) 퀴즈와 최고 점수 저장 파일
```

## 데이터 파일 설명 (state.json)

- 위치: 프로젝트 루트 (`main.py`와 같은 폴더)
- 역할: 프로그램을 종료해도 퀴즈와 최고 점수가 유지되도록 저장
- 인코딩: UTF-8
- 생성 시점: 퀴즈를 풀거나 추가한 직후, 그리고 `Ctrl+C` 종료 시 자동 저장
- Git 관리: 실행하며 계속 바뀌는 기록이라 `.gitignore`에 등록, 저장소에는 올리지 않음

```json
{
    "quizzes": [
        {
            "question": "문제 문장",
            "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
            "answer": 2
        }
    ],
    "best_score": 40
}
```

| 키 | 설명 |
|---|---|
| `quizzes` | 퀴즈 목록 (리스트) |
| `question` | 문제 (문자열) |
| `choices` | 선택지 4개 (문자열 리스트) |
| `answer` | 정답 번호, 1~4 (정수) |
| `best_score` | 최고 점수. 아직 풀지 않았다면 `null` |

> clone/pull 실습: 복제한 저장소에서 작성한 줄입니다.
